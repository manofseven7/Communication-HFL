# Coordinated feature selection and bidirectional low-rank hierarchical FL

Reproducibility release **2.1.0**, accompanying the revised Scientific Reports manuscript. The framework coordinates an aligned feature mask across clients and compresses local, edge and global updates. The release includes the implementation, declared configurations, recorded results, table/figure analysis and tests.

Repository: https://github.com/manofseven7/Communication-HFL

The archival DOI for this new release must be inserted after publication. The older DOI `10.5281/zenodo.21744056` identifies the earlier release, not this update. See `docs/PUBLICATION_GUIDE_FA.md`.

## Install

Use Python 3.10+ in a virtual environment on Linux (file locking and RSS reporting use Linux APIs).

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

For GPU runs install a mutually compatible PyTorch/torchvision build for your CUDA environment. `requirements-recorded-environment.txt` records captured rerun versions; it is not a portable installation lock. A CPU test environment is documented in `docs/VALIDATION.md`.

## Inspect the recorded results without training or dataset downloads

```bash
python scripts/unpack_results.py
python scripts/revision_outputs.py --stage tabular --results results --out analysis_outputs/tabular
python scripts/revision_analysis.py --results results --out analysis_outputs/statistics
python scripts/analyze_cifar.py
python scripts/summarize_auxiliary.py profile --root results/profile
python scripts/summarize_auxiliary.py scalability --root results/scalability
```

These commands use the bundled records. They do not launch federated training. The first command refuses to overwrite different local results.

## Datasets

- Fashion-MNIST: https://github.com/zalandoresearch/fashion-mnist
- CIFAR-10: https://www.cs.toronto.edu/~kriz/cifar.html
- UCI HAR: https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones

Fashion-MNIST and CIFAR-10 are acquired by the dataset loader. The CIFAR fallback mirror is pinned and checksum-validated. For HAR, extract the official data so that `data/HAR/train/X_train.txt`, `data/HAR/train/y_train.txt`, `data/HAR/test/X_test.txt` and `data/HAR/test/y_test.txt` exist. Raw datasets and model checkpoints are not included.

## Declared protocols

| Group | Clients / edges | Rounds | Seeds | Feature mask |
|---|---:|---:|---|---|
| Main Fashion-MNIST | 50 / 5 | 30 | 42–46 | Off |
| Main HAR | 50 / 5 | 30 | 42–46 | Proposed with and without mask |
| Primary CIFAR-10 | 100 / 5 | 400 | 42–44 | Off |
| HAR validation | 50 / 5 | 30 | 42–44 | Fixed training-only 85/15 split; rho .9/.8/.7 |
| Software profile | 50 / 5 | 1 | 42–44 | Off |
| Client-count sweep | 50–500 / 5–50 | 1 | 42–44 | Off |
| Exploratory CIFAR diagnostics | 100 / 5 | 50 | 42–44 | Off |

The main budget is five local epochs, batch size 64, SGD learning rate .05, rank 10 and Dirichlet alpha .1. The separate scaling protocol uses one local epoch and alpha 1.0. The HAR mask is computed after round 5 and activated at the start of round 6, retaining rho=.70 with fixed score weights (.60,.25,.15).

Main methods: FedAvg, FedProx, SCAFFOLD, FedNova, FedKD-style, PowerSGD-EF, QSGD-8, FedPAQ-8, FedCOM-8, Top-k-EF, Adaptive-TopK-EF, SignSGD-MV and Proposed. HAR additionally includes unmasked Proposed. Baseline adaptations and payload conventions are documented in `REPRODUCIBILITY.md` and the manuscript's Supplementary Table S2.

## Run a new experiment explicitly

```bash
python run.py --dataset har --method proposed --seed 42 --tag fs --fs on --out new_results
python scripts/run_grid.py --group tabular --out new_results
python scripts/run_grid.py --group cifar --out new_results
```

The CIFAR preset uses CUDA. `--device cpu` explicitly selects a different host configuration. Full grids are substantial computations; no training is needed to inspect or rebuild the supplied results. Output files are configuration-checked and completed runs are skipped. Checkpoints are scoped by output path and configuration; continuation restores the model, masks, method state and RNGs. Read only checkpoints generated by your own trusted run. The archive contains no credentials or remote-notebook account state.

## Tests

```bash
python -m pytest -q
```

Tests exercise all baseline paths, feature-mask activation, local epoch accounting, exact CPU checkpoint continuation with two loader/RNG patterns, and finite evaluation endpoints.

## Results and provenance

`recorded_results.zip` contains 193 earlier experiment records, plus six new 50-round diagnostics and three reused control prefixes. The extra QSGD CIFAR seed is retained for provenance but is outside the three-common-seed comparison. The FedAvg accuracy summary uses two finite endpoints (seeds 42 and 44), explicitly identified in the table; the excluded record and numerical audit remain archived. No imputation or best-round substitution is used. CIFAR diagnostics are exploratory and use exact reused rank-10 prefixes; they are not rank-20 results at 400 rounds. Payload is modeled bytes across client–edge, edge–central and downlink links; legacy `comm_mb` fields are MiB.

`executed_source_snapshot.zip` preserves the executed source before release conveniences. `CHANGELOG.md` describes the release changes. CUDA nondeterminism and host differences can affect new numerical runs; the recorded outputs provide the exact basis for the revised figures and tables.
